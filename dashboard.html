检测到的环境
1 最快：Cloudflare 隧道（5 分钟，免账号）

在 Linux 服务器上另一个终端执行：

cloudflared tunnel --url http://localhost:9001

没装先装：curl -fsSL https://pkg.cloudflare.com/cloudflare-main.gpg | sudo tee /usr/share/keyrings/cloudflare-main.gpg >/dev/null

执行后会得到一个 https://xxx.trycloudflare.com，用这个 URL 访问即可。

2 Mac 本地：localhost

把文件拷到本机，cd Dashboard && python3 -m http.server 9001，访问 http://localhost:9001。

3 长期：Tailscale Funnel

装 Tailscale，执行 tailscale funnel 9001，获得带 HTTPS 的 tailnet 域名。

这是浏览器安全模型限制，HTTP 公网下 Web Crypto API 永远不可用，与本应用无关。
